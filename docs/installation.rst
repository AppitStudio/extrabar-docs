Installation
============

Requirements
------------

- macOS 12.4 (Monterey) or later
- Works on Intel and Apple Silicon Macs

Download
--------

Get ExtraBar from `extrabar.app <https://extrabar.app>`_.

Setup
-----

1. Open the downloaded ``.dmg`` file

2. Drag ExtraBar to your Applications folder

3. Open ExtraBar from Applications

4. Enter your license key when prompted

That's it. ExtraBar is ready to use.

Optional: Accessibility
-----------------------

For enhanced keyboard navigation, you can grant accessibility access:

1. Open **System Settings** → **Privacy & Security** → **Accessibility**

2. Click the + button and add ExtraBar

This is not required for basic functionality.

Uninstall
---------

Drag ExtraBar from Applications to Trash.
