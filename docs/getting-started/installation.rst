Installation
============

This guide will help you install ExtraBar on your system.

Requirements
------------

Before installing ExtraBar, ensure you have:

- Requirement one
- Requirement two
- Requirement three

Installation Methods
--------------------

Using Package Manager
~~~~~~~~~~~~~~~~~~~~~

.. code-block:: bash

   # Example installation command
   npm install extrabar

Manual Installation
~~~~~~~~~~~~~~~~~~~

1. Download the latest release
2. Extract the archive
3. Run the installer

Verifying Installation
----------------------

To verify ExtraBar is installed correctly:

.. code-block:: bash

   extrabar --version

You should see the version number displayed.

Next Steps
----------

Once installed, proceed to :doc:`quickstart` to begin using ExtraBar.
