Accessibility
=============

Customize bar size and item labels for better visibility. Open ExtraBar → **Settings** (⚙) → **Accessibility** to access these settings.

Bar size
--------

Control the size of icons and the bar height in floating mode. Three sizes are available:

- **Small** — 20pt icons, 28pt bar height. Compact and minimal.
- **Medium** — 28pt icons, 38pt bar height. Balanced visibility.
- **Large** — 36pt icons, 48pt bar height. Maximum visibility.

Item labels
-----------

Enable **Show Item Names** to display a label when you hover over an item or navigate to it with the keyboard. Useful when you're not sure what an icon represents.
