Appearance
==========

Customize how the floating bar and menu bar icons look. All changes apply instantly.

Open ExtraBar → **Settings** (⚙) → **Appearance** to access these settings.

Background style
-----------------

Choose how the bar background is rendered. Five styles are available:

Default
   Standard frosted glass effect using macOS materials.

Tinted Glass
   Glass effect with a color tint overlay. Pick a tint from the presets (Blue, Purple, Pink, Red, Orange, Green, Teal) or use a custom color.

Solid Color
   Opaque background with a solid color. Presets include Charcoal, Obsidian, Graphite, Slate, Navy, Forest, and Wine — or pick a custom color.

Transparent
   No background at all. Only your app icons are visible.

Liquid Glass
   Enhanced glass effect. Native Liquid Glass support is coming with macOS 26.

Background and tint colors
---------------------------

When using **Solid Color** or **Tinted Glass**, you can pick a color from the built-in presets or use the custom color picker for any color you want.

Border
------

Add a border around the bar. Presets include:

- **Subtle**, **Light**, **Medium** — White borders at varying opacity
- **Accent** — Blue tinted border
- **Gold** — Yellow tinted border
- **Rose** — Pink tinted border
- **None** — No border

A custom color picker is also available.

Corner radius
-------------

Adjust how rounded the bar corners are using the slider (0–14pt) or the quick presets:

- **Square** — 0pt, sharp corners
- **5pt** — Default
- **8pt** — More rounded
- **Pill** — 14pt, fully rounded

Bar size
--------

Control the size of icons and the bar height in floating mode. Three sizes are available:

Small
   20pt icons, 28pt bar height. Compact and minimal.

Medium
   28pt icons, 38pt bar height. Balanced visibility.

Large
   36pt icons, 48pt bar height. Maximum visibility.

Bar position
------------

Set where the floating bar appears on screen:

- **Left** — Aligned to the left edge
- **Center** — Centered on screen (default)
- **Right** — Aligned to the right edge

App icon
--------

Choose the dock and app icon style. Five variants are available:

- Standard
- Black & White
- White & Black
- Dark Purple
- Light Purple

Menu bar icon
-------------

Choose the icon that appears in the macOS menu bar. Six variants are available:

- Default
- Outline Black
- Outline White
- Outline Purple
- Fill Black
- Fill White

Reset
-----

Use the **Reset** button to restore all appearance settings to their defaults.
