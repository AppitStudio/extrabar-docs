Inline Mode
===========

Inline Mode places your apps directly in the macOS menu bar, alongside your existing icons.

How it works
------------

Each app you add appears as its own icon in the menu bar. Click an icon to see its actions.

Setting up Inline Mode
----------------------

Hotkey:
Switch between Menu bar Modes using (``⌥ + ⌘ + M``)

Settings:

1. Open ExtraBar

2. Go to Settings (⚙)

3. Under **Display Modes** change your Menu Bar Mode.
