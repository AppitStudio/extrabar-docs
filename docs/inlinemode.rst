Menu Bar Mode
=============

Menu Bar Mode places your apps directly in the macOS menu bar, alongside your existing icons.

How it works
------------

Each app you add appears as its own icon in the menu bar. Click an icon to see its actions.

Setting up Menu Bar Mode
------------------------

Hotkey:
Toggle between bar positions with ``⌥ + ⌘ + M``

Settings:

1. Open ExtraBar

2. Go to Settings (⚙)

3. Under **Position**, select the **Menu Bar** card.

.. note::

   macOS hides menu bar icons when space runs out. If you have more than ~10 apps, ExtraBar shows a warning — consider the Floating Bar or Notch position, or enable Collapse Mode to group everything under a single icon.
