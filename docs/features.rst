Core Features
=============

Deep Links
----------

Deep links open specific content inside an app — not just the app itself.

**Examples:**

- Open a specific Slack channel, not just Slack
- Join a Zoom meeting directly
- Open a Figma file, frame, or prototype
- Play a Spotify playlist

ExtraBar includes presets with common deep links for popular apps.

Display Modes
-------------

**Inline Mode** (default)
    Actions appear in your native macOS menu bar alongside other icons.

**Floating Bar Mode**
    A separate window that appears on demand with a keyboard shortcut. Auto-hides when not in use.

Switch between modes in Settings.

Keyboard Shortcuts
------------------

**Global hotkey**
    Summon ExtraBar from anywhere with one keystroke.

**Navigation**
    - Numbers (1-9) for quick selection
    - Arrow keys to navigate
    - Enter to execute
    - Escape to close

**Per-action shortcuts**
    Assign custom shortcuts to run specific actions without opening the menu.

Action Types
------------

ExtraBar supports 16 action types:

- Open App
- Open File or Folder
- Open URL or Deep Link
- Run Shell Script
- Trigger macOS Shortcut
- Execute Terminal Command
- Open System Settings pane
- And more...

Every item also has a right-click menu for secondary actions.

App Presets
-----------

ExtraBar includes 36+ presets with smart defaults:

- **Design** — Figma, Photoshop, Sketch
- **Development** — VS Code, Terminal, Cursor
- **Communication** — Slack, Zoom, WhatsApp, Messages
- **Productivity** — Things 3, Obsidian, Raycast, Notion

Select a preset to get started quickly, then customize as needed.

Export & Import
---------------

Save your entire configuration to a file and load it on another Mac.

1. Go to **Settings** → **Export**
2. Save the config file
3. On another Mac, use **Settings** → **Import**

Great for syncing setups or backing up your configuration.
