Custom Icons
============

Replace any app or folder icon in your bar with a custom one. Icons are stored in a local library so you can reuse them across items.

Changing an icon
----------------

1. Open ExtraBar and click **Manage** on a preset
2. Right-click an item and choose **Change Icon**
3. Pick an icon from your library, or import a new one
4. Click **Apply**

To go back to the original icon, click **Revert to Original**.

Importing icons
---------------

There are three ways to add icons to your library:

**Upload from file**

Click **Upload** in the icon picker and select one or more image files. Supported formats:

- PNG (recommended, supports transparency)
- JPEG
- ICNS (macOS icon files)

You can select multiple files at once for batch import.

**Download from URL**

Switch to the **From URL** tab, paste an image URL, and click **Download**. The icon is downloaded and saved to your library.

**Copy from an app**

Icons can also be imported directly from an installed application's bundle.

**SF Symbols**

You can import any SF Symbol as an icon from the built-in symbol picker.

Icon library
------------

All imported icons are saved to your library and can be reused across any item in any preset. You can browse and manage your library in ExtraBar → **Settings** (⚙) → **Icon Library**, which shows **Your Library** and an **Import** section for image files and SF Symbols.

The library supports:

- **Search** — Find icons by name or source
- **Rename** — Give icons a custom display name
- **Delete** — Right-click an icon to remove it from the library

Icons associated with a specific app appear first when you open the picker for that app.

Icon tint
---------

Besides replacing an icon, you can apply a **tint color** to any item's icon. Pick from the preset color palette when editing the item.

Tips
----

- High-resolution icons (512x512 or larger) work best — icons are automatically resized
- PNG with transparency is recommended for a clean look
- Try `macosicons.com <https://macosicons.com>`_ for free icon packs
