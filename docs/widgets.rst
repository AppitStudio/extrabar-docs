Widgets
=======

Widgets are special bar items that go beyond launching apps. Use them to run actions with a click, group items into folders, or access your bookmarks directly from the bar.

Adding a widget
---------------

1. Open ExtraBar and click **Manage** on a preset
2. Click the **+** button to add items
3. Choose a widget type: **Action**, **Folder**, or **Bookmark**

All widgets have a custom name, icon, and icon color.

Action widget
-------------

An action widget puts a single action on your bar as a clickable icon. When **Run on Click** is enabled (the default), clicking the widget executes the action immediately — no menu needed.

Configure an action widget:

- **Action** — Choose any action from the action library (Open, Open URL, Run Script, etc.)
- **Target App** — Optionally set a target application for the action
- **Run on Click** — Execute the action on click instead of opening a menu

Folder widget
-------------

A folder widget groups multiple items behind a single icon. Click it to open a popover with all the items inside.

A folder can contain:

- **Apps** — Add apps with their own action menus
- **Actions** — Add standalone actions
- **Bookmarks** — Add a bookmark list filtered by folder or tag

Manage folder items:

- Drag to reorder
- Click the gear icon to configure an item
- Use **Select** mode to multi-select items for bulk move, copy, or delete operations — items can be moved or copied between apps, folders, and widgets

Apps inside a folder can have their own custom action menus, just like top-level bar items.

Bookmark widget
---------------

A bookmark widget shows your Shiori bookmarks in a popover with search and filtering. Requires a Shiori account.

Display options:

- **Search bar** — Toggle the search field
- **Max visible items** — Limit how many bookmarks appear
- **Sort** — By recent, name, or URL (ascending or descending)

Behavior options:

- **Show favicons** — Display site icons
- **Show folders** — Show folder badges
- **Show tags** — Show tag badges
- **Pinned first** — Pin important bookmarks to the top

Filter options:

- **Folders** — Show bookmarks from specific folders only
- **Tags** — Show bookmarks with specific tags only
- **Saved filter** — Use a saved filter from Shiori
