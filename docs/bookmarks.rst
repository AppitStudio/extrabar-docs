Bookmark Manager
================

Shiori is ExtraBar's built-in bookmark manager. Organize your bookmarks with folders, tags, and search. With a premium plan, you can sync bookmarks across all your Macs.

Open the Bookmark Manager with ``⇧ + ⌘ + B`` or from ExtraBar → **Settings** → **Shiori**.

Getting started
---------------

1. Open ExtraBar → **Settings** (⚙) → **Shiori**
2. Sign in with your license key
3. Import your bookmarks or start adding new ones

After signing in, the Bookmark Manager window becomes available.

Bookmarks
---------

A bookmark has a name, URL, and optional description. You can also assign it to a folder and add tags.

From the Bookmark Manager you can:

- **Add** bookmarks with the Quick Add button
- **Edit** a bookmark's name, URL, description, folder, or tags
- **Delete** bookmarks individually or in bulk with multi-select
- **Search** by name or URL
- **Filter** by folder or tags
- **Pin** important bookmarks
- **Copy** a bookmark's URL to the clipboard

Folders
-------

Organize bookmarks into folders. Folders support:

- Custom names and colors
- Sub-folders (nested hierarchy)
- Custom display order via drag and drop

Tags
----

Tags provide a second layer of organization alongside folders. A bookmark can have multiple tags. Tags have a custom name and color.

Bookmark widget
---------------

You can add a Bookmark Widget to your bar for quick access without opening the full manager. The widget shows your bookmarks in a popover with search, folder filtering, and keyboard navigation.

Import and export
-----------------

**Exporting:**

Export your bookmarks in three formats:

- **JSON**
- **CSV**
- **HTML** (browser compatible)

**Importing:**

Import bookmarks from:

- **File import** — HTML or JSON bookmark files (works with browser exports)

Sync and offline
----------------

Shiori syncs bookmarks across all your Macs automatically. Changes made offline are queued and synced when you reconnect. The sidebar shows sync status and pending changes.

If data gets out of sync, use the **Fix** button in the sidebar to resolve conflicts.

Plans
-----

Shiori offers three tiers:

- **Explorer** (free) — Get started with bookmarks, folders, and tags
- **Professional** — More bookmarks, folders, tags, and saved filters
- **Power User** — Unlimited bookmarks and advanced features

Manage your plan from ExtraBar → **Settings** → **Shiori**.
